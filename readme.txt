== Description ==

Illuminate your website. with the SKT Lights free theme, perfect for showcasing lamps, lighting fixtures, bulbs, chandeliers, luminaires, lanterns, fluorescents, and spotlights. This flexible and scalable theme supports SEO plugins, one-click demo import via Elementor, and WooCommerce compatibility for seamless e-commerce integration. Its built-in call-to-action features and contact form plugin compatibility ensure enhanced user engagement.
